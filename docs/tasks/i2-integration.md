# I2 · 联调

> **阶段**：I 测试、联调、验收（3-4 天）　**依赖**：H、I1　**工时**：约 1 天

## 目标

前后端联调，修复字段/分页/错误码不一致，验证性能与并发。

## 实施步骤

### 1. 前后端对接
- 对接全部 API，修复字段/分页/错误码不一致。

### 2. 大文件验证
- 大文件（如 50MB PDF）性能与超时验证。

### 3. 并发验证
- 并发上传 10 个文档，验证队列与幂等。

## 验收标准

- [ ] 前后端字段/分页/错误码一致。
- [ ] 大文件处理不超时不崩溃。
- [ ] 并发上传队列与幂等正常。
